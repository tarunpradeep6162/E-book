# Companion source

The chapter-number directories contain the complete code shown before the illustrated edition splits longer files into reading panels. New minimum-contract examples in the manuscript are explanatory excerpts, not alternate executable releases.

Start with terraform-foundation/ for Chapter 2's root. Chapter 3 separates bootstrap and workload backend files: do not execute backend.tf inside bootstrap. Chapter 5 preserves module/root paths. Read each chapter's prerequisites and replace explicit identifiers and image digests before execution. Partial deployment snippets remain labeled in manifest.json.

The public repository is https://github.com/tarunpradeep6162/E-book. No application, data, credential, or live-cloud validation is implied by code availability.
